About AgriPrice Intelligence

🎯 Our Mission

AgriPrice Intelligence gives Tamil Nadu farmers, traders, and consumers real-time commodity price data powered by AI — so they can make smarter decisions without depending on middlemen.

This project was built to solve a real local problem: price opacity in agricultural markets. Data is fetched automatically from Agmarknet and enriched with AI-generated advisory using Google Gemini.

⚙️ Technology Stack

🐍 Python / Flask
🐘 PostgreSQL (Neon)
🤖 Google Gemini AI
🌐 Agmarknet API
🌦️ OpenWeatherMap
📊 Chart.js
🎨 Tailwind CSS
☁️ Render (Deploy)

📡 Data Sources

🏛️

Agmarknet (data.gov.in)

Official Government of India agricultural market price data. Auto-fetched daily via cron-job.org.

🌦️

OpenWeatherMap API

Live weather data for key Tamil Nadu districts. Used for agricultural context in AI advisories.

🤖

Google Gemini 2.5 Flash

Market advisory generated based on live price data, trend analysis, and weather context.

🔍 SQL Analytics Engine

7 complex queries powering the analytics dashboard:

  • • Window functions — price rank per market per commodity
  • • CTEs — 7-day rolling average trend calculation
  • • STDDEV — volatility scoring across markets
  • • Self JOIN — highest vs. lowest price market arbitrage detection
  • • Subqueries — seasonal profit scoring per crop
  • • TO_CHAR — formatted date series for Chart.js
  • • DENSE_RANK — top market ranking by volume

Data sourced from data.gov.in
